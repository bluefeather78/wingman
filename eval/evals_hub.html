Evals

Every eval we maintain, each recorded run, and how each metric moved run over run. Add a run by appending to eval/runs.json — the graphs below extend on their own.

← Agent Ops console
How this works. eval/registry.json defines each eval and its metrics (with a direction saying which way is better). eval/runs.json holds one row per run. This page joins them: a card per eval up top, then a trend section per eval plotting every metric across its runs. A run-over-run delta is colored green when it moved the good way and red when it moved the wrong way. With a single datapoint there is no delta yet — the line begins as the next run lands.
